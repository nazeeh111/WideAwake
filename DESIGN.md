# WideAwake visual identity

Quiet, precise, functional. A static sunrise replaces the inherited eye. Native macOS controls; no animated interface or live seconds counter.

Colors: ink #132C35, warm paper #F8F3E9, sunrise #F0AB32, muted #66767A. System appearance remains respected inside the actual native panel.
Typography: native SF Pro / system sans serif. Tabular numerals for the duration. No extra font dependencies.
Presentation: roomy ink canvas, one clear statement, actual app screenshots, sharp cuts. No fake dashboard, neon glow, floating feature cards, gradients, exaggerated claims, or narration. Deliberately silent demonstration.
